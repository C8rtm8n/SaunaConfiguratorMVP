# M5 – Administrace a seed: stav

Stav: **hotovo**. `apps/admin` (Preact + Vite), admin endpointy v `apps/api/src/routes/admin.ts`, validace a převod katalogu
do tabulek v `@sauna/core`.

## Funkce

- **Přihlášení:** e-mail + výrobce → magic link → session cookie. Role `admin` / `sales`.
- **Poptávky:** seznam s filtrem a změnou stavu (nový / v jednání / vyhráno / prohráno). Detail obsahuje kontakt, konfiguraci
  (rozměry, zóny, cenu, náklad, marži, hmotnost, objem sauny, elektro, verzi katalogu), exporty (offer.pdf, tech.pdf,
  bom.xlsx, bom.csv, config.json), foto místa, vizualizace od zákazníka, upozornění, revize a odkaz do konfigurátoru.
- **Katalog:** tabulky pro profily, ocel, obklady a plošné materiály, kamna (výkon, objemy, odstupy, rozměry, hmotnost
  s kameny, min. výška kabiny, napětí, cena), okna/dveře/skla (rozměry, sloty, světlá šířka, plocha skla), světla
  a příslušenství, řezivo a terasy. Skladby, rámy, pravidla a limity se upravují v JSON editoru nebo přes XLSX. Přidání řádku
  (kopie), odebrání, kontrola (diff + chyby + upozornění) a publikace nové verze. Export a import XLSX s náhledem.
- **Sazby:** práce, doprava (Kč/km, paušál, výchozí vzdálenost, příplatek za nadrozměr), autojeřáb, marže po kategoriích,
  režim zobrazení ceny (skrytá / rozpětí / přesná), šíře rozpětí, zaokrouhlení a kurz EUR. Publikují se jako verze katalogu.
- **Nastavení:** název, barvy, zaoblení, písmo, logo (s náhledem), jazyky a měny, e-mail pro poptávky, webhook (URL + secret),
  URL stránky s konfigurátorem, povolené weby pro embed a kód pro vložení.

## Ověření

- `@sauna/core`: 85 testů, nově validace katalogu a XLSX round-trip.
  - Validace najde rozbité odkazy, chybné rozsahy, duplicitní SKU i neznámou funkci v pravidlech.
  - Katalog → tabulky → katalog je beze ztráty. Nová kamna přidaná jako řádek jsou platná položka.
- `@sauna/api`: 27 testů, nově `admin.test.ts`.
  - Sales nastavení jen čte a secret webhooku nikdy nedostane.
  - Theming se propíše do veřejného endpointu; nevalidní barva, jazyk nebo `javascript:` logo vrátí 400.
  - Katalog: suchý běh nic nepublikuje, publikace vytvoří `demo-2`, veřejné ceny ji následují a stará revize zůstává
    na `demo-1`. Nevalidní katalog vrátí 422.
  - **Nová kamna přidaná v adminu jdou bez změny kódu použít v konfiguraci.**
  - XLSX export → úprava sazby → import (náhled, pak publikace). Rozbitý multipart vrátí 400.
  - Detail poptávky; izolace tenantů.
- `pnpm --filter @sauna/api e2e:admin`: admin v prohlížeči proti API, 14 kontrol. Screenshoty a vzorový `katalog-export.xlsx`
  jsou v `docs/m5/`.
  - Přihlášení magic linkem, změna stavu poptávky, stažení offer.pdf.
  - Cena kamen: suchý běh s diffem, publikace a nová cena ve veřejném katalogu.
  - **Nové okno 1 200 × 600 přidané v tabulce je v katalogu konfigurátoru a API ho přijme v konfiguraci.**
  - Nevalidní změnu nejde publikovat.
  - Sazby a režim ceny, theming.
  - Náhled importu XLSX bez změn (round-trip).
  - Sales vidí vše jen pro čtení a API zápis odmítne (403).

## Lokální běh

```sh
pnpm --filter @sauna/api dev                     # API :3000 (PGlite, seed demo tenanta)
VITE_API_BASE=http://localhost:3000 pnpm --filter @sauna/admin dev   # admin :5174
# přihlášení: admin@demo-sauny.example, tenant demo → odkaz v GET http://localhost:3000/dev/outbox
```
