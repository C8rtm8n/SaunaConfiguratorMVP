# M2 – Viewer: stav

Stav: **hotovo**. Balíček `packages/viewer` (Three.js r186, vanilla TS), demo stránka `packages/viewer/demo`.

## API

```ts
import { SaunaViewer } from '@sauna/viewer';
const viewer = new SaunaViewer(element, { materials: { thermowood: { color: '#6b4a2f' } } });
viewer.setScene(evaluate(config, catalog).scene);   // diff podle id + hash
viewer.setSectionMode(true);                        // řez: střecha + stěna u kamery
viewer.on('slotclick', ({ wall, index }) => …);    // klik do slotu (S/N/E/W/P1/roof)
viewer.highlightSlots([{ wall: 'S', index: 3 }]);
const shots = await viewer.exportSnapshots();       // 4 × PNG 1600 × 1000
viewer.stats(); viewer.dispose();
```

| Soubor | Obsah |
|---|---|
| `src/convert.ts` | SceneNode → Three.js: instancované boxy, prkna a pruty (jednotková extruze průřezu), panely s otvory, válce, GLB assety s placeholderem |
| `src/sync.ts` | `SceneSync` – diff komponent, převod mm/Z-up → m/Y-up |
| `src/materials.ts` | PBR knihovna materiálů (id z katalogu `appearance`), přepis pro tenanta, textura spár lamel |
| `src/section.ts` | výběr stěny pro řez |
| `src/quality.ts` | třída zařízení, adaptivní DPR a stíny |
| `src/viewer.ts` | renderer, orbit kamera, prostředí, stíny, picking, hover, snímky |

## Ověření

- `pnpm --filter @sauna/viewer test`: 13 unit testů v Node bez WebGL.
  - Každý uzel scény je převedený právě jednou, REF-1..3 dávají 52 / 67 / 74 meshů ze 113 / 134 / 104 uzlů.
  - Obálka modulu v metrech odpovídá core.
  - Konce prutů leží na `from`/`to` s kladným determinantem.
  - Diff: posun kamen přestaví jen 3 komponenty, odebrání terasy odstraní 3 komponenty.
  - Řez a adaptivní kvalita.
- `pnpm --filter @sauna/viewer build:demo && pnpm --filter @sauna/viewer e2e`: Chromium (SwiftShader), 9 kontrol.
  Výstupy jsou v `docs/m2/`.
  - REF-1..3 se vyrenderují bez chyb v konzoli (105 / 135 / 149 draw calls včetně stínového průchodu, 3–5 tis. trojúhelníků).
  - Řez skryje celou střechu a nechá zadní stěnu.
  - Skutečný klik myší na slot S/1 vyvolá `slotclick`.
  - Posun kamen přestaví jen kamna, komín a větrání.
  - `exportSnapshots()` vrátí 4 PNG 1 600 × 1 000 (`docs/m2/snapshots/`).
  - Mobil: 390 × 844, DPR 3, CPU 4× zpomalené, gzip jako z CDN.

| Profil | Čas do interakce (1. snímek) |
|---|---|
| 4G (9 Mbit/s, RTT 170 ms) | **2,7 s** |
| pomalé 4G (1,6 Mbit/s, RTT 150 ms) | 3,6 s |

Úvodní načtení: `index.html` + 1 JS (Three.js + core + demo) = 744 kB, **201 kB gzip** (limit 3 MB). Loadery a dekodéry
(GLTF, Draco, KTX2, Meshopt, HDR) jsou v samostatných chuncích a stahují se jen při použití.

## Omezení měření

- Prohlížeč v kontejneru kreslí WebGL softwarově (SwiftShader), takže čísla jsou pesimistická a **fps se tu změřit nedá**.
  Cíl 60 fps na desktopu a ≥ 30 fps na mobilu ověřím v M6 na reálných zařízeních. Scéna má kolem 5 tis. trojúhelníků
  a ~70 meshů, takže rezerva je velká.
- Demo nemá vlastní GLB assety ani HDRI (katalog zatím nemá `asset`). Loader je hotový a placeholder je box se stejnými rozměry.
