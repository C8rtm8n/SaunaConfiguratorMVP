# M4 – API a výstupy: stav

Stav: **hotovo**. `apps/api` (Fastify 5, Drizzle, PostgreSQL / PGlite, Playwright Chromium pro PDF, nodemailer, ExcelJS).

## Endpointy

| Metoda | Cesta | Přístup | Popis |
|---|---|---|---|
| GET | `/tenants/:slug/public` | veřejné | theming, jazyky, měny, katalog s prodejními cenami (bez nákladů a marží) |
| POST | `/configs` | veřejné | nová konfigurace → server přepočítá → revize 1 |
| PUT | `/configs/:id?tenant=` | veřejné | nová revize (jen v rámci tenanta) |
| GET | `/configs/:id?tenant=&revision=` | veřejné | sdílený odkaz, bez nákladů |
| POST | `/leads` | veřejné | multipart: `payload` JSON, `photo`, `snapshot_<view>`; 422 při chybové konfiguraci |
| GET | `/configs/:id/exports/{bom.csv,bom.xlsx,config.json,offer.pdf,tech.pdf}` | admin/sales | `?revision=`, `?lang=` |
| POST | `/auth/magic-link` · GET `/auth/verify` · POST `/auth/logout` · GET `/auth/me` | – | přihlášení e-mailem |
| GET/PATCH | `/admin/leads`, `/admin/leads/:id` | admin/sales | seznam, detail, stav (nový / v jednání / vyhráno / prohráno) |
| GET | `/admin/files/:id`, `/admin/configs/:id/revisions` | admin/sales | soubory poptávky, historie revizí |
| GET | `/dev/outbox` | jen vývoj | odeslané e-maily (SMTP_URL=memory) |

## Tok poptávky

Konfigurátor (s `VITE_API_BASE`) při odeslání vyrenderuje 4 snímky 1 600 × 1 000 a pošle je s poptávkou. Server konfiguraci
přepočítá a uloží jako revizi, uloží foto a snímky, vytvoří poptávku a zařadí úlohu. Worker pak vyrobí `nabídka.pdf`,
`technický list.pdf` a `kusovník.xlsx` a pošle e-mail výrobci (3 přílohy + foto) i zákazníkovi (nabídka v jeho jazyce).
Nakonec zavolá webhook tenanta s HMAC podpisem.

## Ověření

- `pnpm --filter @sauna/api test`: 17 testů na PGlite i na skutečném PostgreSQL 16 (`TEST_DATABASE_URL=postgres://…`).
  - Veřejný katalog neobsahuje náklady, e-mail výrobce ani webhook.
  - Serverová cena se rovná ceně v prohlížeči; podvržená data cenu nezmění.
  - Revize přibývají a starší jdou načíst.
  - Nevalidní vstup vrací 400, neznámá položka katalogu 422, cizí tenant 404.
  - Poptávka s chybou vrací 422; chybí-li souhlas, je vyplněný honeypot nebo přijde nepovolený soubor, vrací 400 nebo 415.
  - Poptávka dojde v e-mailu výrobci (2 × PDF, XLSX, foto) i zákazníkovi (DE) a webhook má platný podpis, celé za ~0,9 s.
    Neúspěšný webhook se opakuje s odkladem.
  - Magic link: neznámý e-mail nepošle nic, odkaz jde použít jen jednou, cookie je HttpOnly + SameSite=Lax, odhlášení ji zneplatní.
  - Exporty: bez přihlášení 401; CSV, XLSX se 4 listy, JSON a 2 × PDF.
  - Izolace tenantů (D-042).
- `pnpm --filter @sauna/api e2e`: prohlížeč, konfigurátor sestavený proti API, 8 kontrol.
  - Načtení tenanta z API, uložení revize, odeslání poptávky.
  - Na serveru jsou 4 snímky a PDF nabídky je obsahuje.
  - **Poptávka s oběma PDF a XLSX je doručená za 5,3 s** (limit 1 min; včetně renderu snímků v prohlížeči).
  - Sdílený odkaz načte konfiguraci ze serveru.
- Ukázkové výstupy pro REF-1..3 (`pnpm --filter @sauna/api docs:samples`) jsou v `docs/m4/`: `ref-*-offer.pdf`, `ref-*-tech.pdf`,
  `ref-*-bom.xlsx`, `ref-*-bom.csv`, `ref-*-config.json` a náhledy stránek `preview-*.png`.

## Lokální běh

```sh
pnpm --filter @sauna/api dev          # API na :3000, PGlite v apps/api/.data, demo tenant + admin@demo-sauny.example
VITE_API_BASE=http://localhost:3000 pnpm dev   # konfigurátor proti API
curl -X POST localhost:3000/auth/magic-link -H 'content-type: application/json' -d '{"tenant":"demo","email":"admin@demo-sauny.example"}'
curl localhost:3000/dev/outbox        # odkaz pro přihlášení
```
